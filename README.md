Калькулятор вклада
Создать одностраничное приложение с формой. Пользователь вводит параметры вклада → отправляет на сервер → получает результат расчета.
Backend (Java Spring Boot)
1. Endpoint
POST /api/calculate
2. Входные данные (JSON)
{
  "amount": 100000,
  "months": 12,
  "rate": 8.5
}
•	amount — сумма (от 1000 до 10 млн)
•	months — срок в месяцах (от 1 до 60)
•	rate — годовая ставка (от 1% до 20%)
3. Логика расчета
Формула (с капитализацией):
Итог = Сумма × (1 + Ставка/100/12) ^ Срок_в_месяцах
Прибыль = Итог - Сумма
4. Ответ (JSON)
{
  "total": 108300.50,
  "profit": 8300.50
}
5. Что нужно сделать:
1.	Создать Spring Boot приложение с контроллером
2.	Реализовать endpoint /api/calculate
3.	Добавить валидацию входных данных
4.	Реализовать расчет по формуле
5.	Использовать BigDecimal для точности

Frontend (React + TypeScript)
1. Интерфейс
 [ Сумма вклада:     100 000 ₽     ]
[ Срок (месяцы):    12           ]
[ Годовая ставка:   8.5 %        ]
         [ Рассчитать ]
                 
Начальная сумма: 100 000 ₽
Итоговая сумма:  108 300.50 ₽
Доход:            8 300.50 ₽
2. Что нужно сделать:
1.	Создать форму с тремя полями ввода
2.	Кнопку "Рассчитать"
3.	При нажатии отправлять POST-запрос на /api/calculate
4.	Показывать результаты под формой
5.	Добавить простую валидацию (числа > 0)
